About This Project

A B.E. CSE (AI&ML) Major Project that uses Natural Language Processing and Machine Learning to automatically classify news articles as real or fake — built by Tanmay, Simar, and Nevia at Chandigarh University.

TECH STACK

Python + Flask

Backend web framework handling routing and REST API

scikit-learn

ML library — Logistic Regression + TF-IDF vectorization

NLTK

Text preprocessing: stopword removal, lemmatization

Pandas / NumPy

Dataset loading, manipulation, and analysis

NLP PIPELINE
01

Text Cleaning

Lowercase, remove URLs, HTML tags, punctuation, and digits.

02

Stopword Removal

Common English words (the, is, at…) are removed using NLTK stopwords.

03

Lemmatization

Words reduced to their root form (running → run) using WordNetLemmatizer.

04

TF-IDF Vectorization

Text converted to numerical feature vectors using Term Frequency–Inverse Document Frequency with bigrams.

05

Classification

Logistic Regression model trained on labeled dataset predicts FAKE or REAL with confidence score.
